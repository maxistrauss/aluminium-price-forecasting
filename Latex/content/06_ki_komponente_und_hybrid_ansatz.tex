\section{KI-Komponente: Multi-Task LSTM}
\label{sec:ki_komponente}

Die Architektur des Vorhersagemodells basiert auf einem rekurrenten neuronalen Netz, das speziell für die Extraktion zeitlicher Abhängigkeiten in verrauschten Daten konzipiert ist. Im Gegensatz zu Standardmodellen wird hier ein Multi-Task-Ansatz verfolgt, der mehrere Vorhersageziele gleichzeitig optimiert.

\subsection{Architektur und Datenfluss}
Das Modell nutzt eine hierarchische Struktur, die sich in drei Hauptkomponenten unterteilen lässt:
\begin{enumerate}
    \item Shared LSTM Backbone (Gemeinsame Basis): Den Kern bildet ein zweischichtiges LSTM-Netzwerk (Long Short-Term Memory) mit 64 verborgenen Einheiten (Hidden Units). LSTMs sind durch ihre Gating-Architektur in der Lage, Informationen über längere Zeiträume zu speichern und das Problem verschwindender Gradienten zu umgehen. Das funktioniert, indem sie entscheiden, welche Informationen behalten oder vergessen werden sollen, was besonders bei Finanzzeitreihen mit hohem Rauschen von Vorteil ist. In diesem Projekt verarbeitet das Backbone Eingabesequenzen der vorangegangenen 21 Handelstage.
    \item Shared Projection Layer (Merkmalsverdichtung): Die vom LSTM extrahierten Zustandsvektoren werden in eine dichte Schicht (32 Einheiten) projiziert. Hier kommen \emph{Layer Normalization} zur Stabilisierung der Aktivierungen und die \emph{GELU-Aktivierungsfunktion} (Gaussian Error Linear Unit) zum Einsatz.  Das funktioniert durch die Normalisierung der Eingaben auf eine Standardnormalverteilung, was den Lernprozess beschleunigt und die Konvergenz verbessert. Die GELU-Funktion führt eine nichtlineare Transformation durch, die weiche Schwellenwerte ermöglicht und somit eine bessere Modellierung komplexer Muster in den Daten erlaubt. Dieser Schritt dient der weiteren Abstraktion und Verdichtung der Merkmale.
    \item Multi-Horizon Heads (Spezialisierte Ausgabeschichten): Das Modell verfügt über 28 unabhängige lineare Ausgabeköpfe. Diese Struktur ermöglicht das sogenannte \emph{Inductive Transfer Learning}: Das Modell lernt eine gemeinsame Repräsentation für alle Aufgaben (7 Metalle) und Horizonte ($h \in \{1, 5, 10, 21\}$), nutzt aber spezialisierte Schichten für die finale Prognose. So eine Schicht besteht aus einer einzigen linearen Transformation, die die 32-dimensionale Repräsentation in eine Punktvorhersage für den jeweiligen Metall-Horizont-Kombination umwandelt. Beispielsweise ist ein Kopf für die Vorhersage des Aluminiumpreises in 5 Tagen zuständig, während ein anderer Kopf die Prognose für den Kupferpreis in 10 Tagen liefert. Dies führt in der Regel zu einer robusteren Merkmalswahl, da das Modell gezwungen ist, Informationen zu extrahieren, die für mehrere Ziele relevant sind.
\end{enumerate}

\subsection{Optimierung der Vorhersagehorizonte}
Die Vorhersage bezieht sich auf die summierten Log-Returns über verschiedene Horizonte $h$. Mathematisch wird das Ziel für einen Zeitpunkt $t$ wie folgt definiert:
\begin{equation}
    y_{t,h} = \sum_{i=1}^{h} r_{t+i} = \ln(P_{t+h}) - \ln(P_t)
\end{equation}
Durch die Aggregation über mehrere Tage erhöht sich das Signal-Rausch-Verhältnis (Signal-to-Noise Ratio, SNR). Während tägliche Schwankungen ($h=1$) primär stochastisches Rauschen darstellen, treten bei längeren Horizonten (z. B. $h=21$) Trends deutlicher hervor. Das Training erfolgt durch die Minimierung des \emph{Mean Squared Error}, wobei ein Maskierungsverfahren sicherstellt, dass nur die relevanten Ausgabeköpfe für die jeweiligen Aufgaben aktualisiert werden. Beispielsweise wird bei der Berechnung des Fehlers für die Aluminium-5-Tage-Vorhersage ausschließlich der entsprechende Kopf berücksichtigt, während die anderen 27 Köpfe ignoriert werden.

\subsection{Unsicherheitsschätzung mittels Monte Carlo Dropout}
Ein zentrales Merkmal des Systems ist die Abkehr von reinen Punktvorhersagen. Um die Modellunsicherheit zu bestimmen, wird \emph{Monte Carlo Dropout} (MC-Dropout) angewendet. Dropout wird üblicherweise als Regularisierungstechnik während des Trainings eingesetzt. Beim MC-Dropout bleibt diese Technik auch während der Inferenz (Vorhersagephase) aktiv. Durch die Durchführung von 30 stochastischen Vorwärtspässen pro Datenpunkt entsteht eine Verteilung der Vorhersagen. Der empirische Mittelwert dieser Verteilung dient als Prognose, während die Standardabweichung als Maß für die Unsicherheit des Modells interpretiert wird. Dies ermöglicht die Konstruktion von 95\%-Konfidenzintervallen, die anzeigen, in welchem Bereich sich der Preis mit hoher Wahrscheinlichkeit bewegen wird.

\subsection{Verwendete Modelle}

\subsubsection{LSTM}

Ein LSTM-Netzwerk (Long Short-Term Memory) ist ein von Sepp Hochreiter und Jürgen Schmidhuber im Jahr 1997 entwickeltes Verfahren \cite{lstm}, das im Gegensatz zu anderen rekurrenten neuronalen Netzwerken ein Kurzzeitgedächtnis modellieren kann. Dies geschieht durch drei Arten von Toren: das Eingangstor, das Vergessens- bzw. Merktor sowie das Ausgangstor. Diese ermöglichen bei der Rückführung des Fehlersignals eine effektivere Aktualisierung der Gewichte.

Aufgrund seiner Speicherfähigkeit eignet sich ein LSTM-Netzwerk besonders gut zum Lernen von Zeitreihen und wird daher in dieser Arbeit als zentrales Modell zur Vorhersage eingesetzt.


\subsubsection{Mean Baseline}

Eine Baseline wird in der Auswertung eines Modells verwendet um zu vergelichen ob das trainierte Modell bessere Performance liefert.
Die Mean Baseline liefert wie der Name impliziert den Mittelwert der Trainingsdaten als Vorhersage.

\subsubsection{Naive Baseline (-1)}

Die Naive Baseline liefter als Vorhersage den Wert der Letzten Eingabe zurück.

\subsubsection{XGB Regressor}

XGB (Extreme Gradient Boosting) ist ein Regressionsmodell das Vorhersagen mit einer Folge von Entscheidungsbäumen trifft.
Durch die Folge an Bäumen können sowohl nicht lineare Zusammenhänge als auch Zeitreihen modelliert werden.


\subsubsection{LGMB Regressor}

LGMB (Light Gradient Boosting Machine) ist eine auf Geschwindigkeit optimierte Version von XGB.
Es ist dabei bei großen Datenmengen effizenter als XGB.

\subsubsection{SVR}

SVR (Support Vector Regressor) ist eine Variante der SVM (Support Vector Machine) für Regressionsmodelle.
Das Verfahren ist robust gegen overfitting und kann komplexe Muster erfassen, weswegen es häufig für die Prognose von Werten verwendet wird.

\subsubsection{KNN}

KNN (K-Nearest Neighbors Regressor) liefert Vorhersagen aufgrund ähnlich Punkte in den Trainingsdaten 
Dazu Müssen erst die Vergleichswerte (Lag Werte) aus den Trainingsdaten erzeugt werden.
Für Vorhersagen werden dann diese Werte überprüft und aus den ähnlichsten werten der mittelwert gebildet.

\subsubsection{Lineare Regression}

Die Lineare Regression ist das standart Verfahren um Lineare Zusammenhänge in Daten Vorherzusagen.
Die Daten Werden durch eine Gerade angenähert und es können neue Daten aufgrund dieser Gerade vorhergesagt werden.

\subsubsection{Ridge Regression}

Die Ridge Regression ist eine Erweiterung der Linearen Regression um L2-Regularisierung, die die größe der Koeffizenten minimieren und so overfitting verhindern soll.
